# RobotLight — website

The support and privacy pages for RobotLight, a light show for the music your Mac is playing.

* [Support](https://haj728.github.io/robotlight-site/support.html)
* [Privacy Policy](https://haj728.github.io/robotlight-site/privacy.html)

This repository contains only these pages. The app's source code is not here.

The pages are written in the app's own repository, under `Site/`, and copied
here by hand. Editing a file here without doing the same there means the next
copy quietly overwrites it.

Bug reports and questions about the app are welcome in [Issues](https://github.com/HAJ728/robotlight-site/issues).
